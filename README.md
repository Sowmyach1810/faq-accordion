# FAQ Accordion

A simple and responsive FAQ Accordion web application that allows users to expand and collapse frequently asked questions.

## Features
- 8 frequently asked questions
- Expandable and collapsible answers
- Interactive plus and minus icons
- Active question highlighting
- Multiple answers can remain open
- Responsive design for mobile and desktop

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Open the FAQ Accordion application.
2. Click on any question to view its answer.
3. Click the same question again to hide the answer.
4. Click another question to view its answer.
